Experiment: Load Balancer Using HAProxy in Ubuntu 

Complete practical procedure 

Single Ubuntu machine 

Below is the complete experiment from beginning to end. You can copy the entire response into 
your Word document and follow it during your practical examination. 

We will create two backend web servers on one Ubuntu machine and use HAProxy as the load 
balancer. 

1. Aim 

To implement a load balancer using HAProxy in Ubuntu and distribute incoming client requests 
among multiple backend servers using the Round Robin algorithm. 

2. Objectives 

1. To install HAProxy in Ubuntu. 

2. To create two backend web servers. 

3. To configure HAProxy as a load balancer. 

4. To distribute client requests among backend servers. 

5. To test load balancing functionality. 

3. Requirements 

• Ubuntu operating system 

• Internet connection 

• Terminal 

• HAProxy 

• Python 3 

• Web browser

Client / Browser

Round Robin Algorithm

Backend Server 2

5. Procedure 

Step 1: Update Ubuntu 

Command 1: 

sudo apt update 

Explanation: Updates the package lists of Ubuntu. 

Command 2: 

sudo apt upgrade -y 

Explanation: Installs available software updates. 

Step 2: Install HAProxy 

Command: 

sudo apt install haproxy -y 

Explanation: Installs the HAProxy load-balancing software. 

Check installation: 

haproxy -v 

Expected output: HAProxy version information. 

Step 3: Check Python installation 

Python will be used to create two simple web servers. 

python3 --version 

If Python is not installed, execute: 

sudo apt install python3 -y 

Step 4: Create Backend Server 1 

Create a directory for Server 1. 

mkdir -p ~/server1 

Move into the directory:

Create an HTML file:

Server 1 running on port 8081

Step 6: Test Both Backend Servers 

Open a third terminal. 

Test Server 1:

Expected output contains:

Test Server 2: 

curl http://localhost:8082 

Expected output contains: 

<h1>Welcome to Backend Server 2</h1> 

Explanation: These commands verify that both backend servers are working properly before 
configuring HAProxy. 

Step 7: Configure HAProxy 



Open the HAProxy configuration file: 

sudo nano /etc/haproxy/haproxy.cfg 

Go to the bottom of the file and add the following configuration. 

HAProxy configuration code: 

frontend http_front 

    bind *:80 

    default_backend web_servers 

 

backend web_servers 

    balance roundrobin 

    server server1 127.0.0.1:8081 check 

    server server2 127.0.0.1:8082 check 

Save the file: 

• Press Ctrl + O. 

• Press Enter. 

• Press Ctrl + X. 

Explanation of configuration: 

Configuration Meaning 

frontend http_front Defines the frontend 

bind *:80 Listens on port 80 

default_backend Specifies backend servers 

backend web_servers Defines backend group 

balance roundrobin Uses Round Robin algorithm 

server server1 Defines first server 

server server2 Defines second server 

check Enables server health checks 

Important: The check option allows HAProxy to monitor backend server availability. 

Step 8: Validate HAProxy Configuration 

Before starting HAProxy, check the configuration for errors. 

sudo haproxy -c -f /etc/haproxy/haproxy.cfg 



Expected output: 

Configuration file is valid 

If the configuration is invalid, check the configuration file and correct the errors. 

Step 9: Restart HAProxy 

Execute: 

sudo systemctl restart haproxy 

Enable HAProxy to start automatically during system boot: 

sudo systemctl enable haproxy 

Check HAProxy status: 

sudo systemctl status haproxy 

Expected output: 

Active: active (running) 

Press q to exit the status screen.

7. Troubleshooting 

Problem Solution 

HAProxy installation failed Run sudo apt update 

Port 80 already in use Check using sudo ss -ltnp 

Server 1 not responding Check whether port 8081 is running 

Server 2 not responding Check whether port 8082 is running 

HAProxy configuration error Run configuration validation command 



HAProxy not starting Check sudo journalctl -u haproxy -n 50 

Important configuration note: Ubuntu's default HAProxy configuration may already contain an 
active frontend listening on port 80. To avoid duplicate port bindings, replace the entire existing 
configuration file with this complete configuration rather than simply appending another frontend. 

sudo tee /etc/haproxy/haproxy.cfg > /dev/null <<'EOF' 

global 

    log /dev/log local0 

    log /dev/log local1 notice 

    daemon 

    maxconn 256 

 

defaults 

    log global 

    mode http 

    option httplog 

    timeout connect 5s 

    timeout client 30s 

    timeout server 30s 

 

frontend http_front 

    bind *:80 

    default_backend web_servers 

 

backend web_servers 

    balance roundrobin 

    option httpchk GET / 

    server server1 127.0.0.1:8081 check 

    server server2 127.0.0.1:8082 check 

EOF 

Then validate and restart: 

sudo haproxy -c -f /etc/haproxy/haproxy.cfg 



sudo systemctl restart haproxy 

Use this complete configuration if you encounter conflicts with the default configuration.

10. Viva Questions and Answers 

1. What is a load balancer? 

A load balancer distributes incoming network traffic among multiple servers to improve 
performance and availability. 

2. What is HAProxy? 

HAProxy stands for High Availability Proxy. It is open-source software used for load balancing and 
proxying TCP and HTTP traffic. 

3. What is the purpose of HAProxy? 

It distributes client requests among multiple backend servers and prevents a single server from 
becoming overloaded. 

4. What is Round Robin? 



Round Robin is a load-balancing algorithm that distributes requests sequentially among available 
servers. 

5. What is a frontend in HAProxy? 

Frontend is the component that receives incoming client connections. 

6. What is a backend? 

Backend is a group of servers that process client requests forwarded by HAProxy. 

7. What is a health check? 

A health check verifies whether a backend server is available and responding. 

8. What is port 80? 

Port 80 is the default port used for HTTP communication. 

9. What is the use of the curl command? 

It sends HTTP requests and displays the server response through the terminal. 

10. What happens if one backend server fails? 

HAProxy detects the failure through health checks and forwards requests to the remaining healthy 
servers. 

11. What are other load-balancing algorithms? 

• Round Robin 

• Least Connections 

• Source IP 

12. What is the difference between frontend and backend? 

Frontend receives client requests, whereas backend processes the requests through configured 
servers.
