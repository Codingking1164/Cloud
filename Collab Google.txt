### **Cell 4 – Extract channel ID and fetch channel details**

This code identifies the channel and retrieves its basic information.

```
def get_channel_id(channel_url):    channel_url = channel_url.strip()    # Direct channel ID    if channel_url.startswith("UC") and "/" not in channel_url:        return channel_url    # Extract @handle from URL or direct handle    match = re.search(r"@([A-Za-z0-9._-]+)", channel_url)    if match:        handle = "@" + match.group(1)        response = youtube.channels().list(            part="snippet,statistics,contentDetails",            forHandle=handle        ).execute()    else:        raise ValueError(            "Please enter a valid @handle URL or UC channel ID."        )    if not response.get("items"):        raise ValueError("Channel not found!")    return response["items"][0]["id"]# Get channel IDchannel_id = get_channel_id(CHANNEL_URL)# Fetch channel detailschannel_response = youtube.channels().list(    part="snippet,statistics,contentDetails",    id=channel_id).execute()channel = channel_response["items"][0]# Extract informationchannel_name = channel["snippet"]["title"]description = channel["snippet"]["description"]stats = channel["statistics"]subscribers = int(stats.get("subscriberCount", 0))total_views = int(stats.get("viewCount", 0))total_videos = int(stats.get("videoCount", 0))uploads_playlist = channel["contentDetails"]["relatedPlaylists"]["uploads"]print("\n========== CHANNEL DETAILS ==========")print("Channel Name:", channel_name)print("Channel ID:", channel_id)print("Subscribers:", subscribers)print("Total Views:", total_views)print("Total Videos:", total_videos)print("Description:", description[:300])
```


### **Cell 6 – Extract views, likes, comments and other details**

Now we will retrieve detailed information for each collected video.

```
video_data = []# YouTube API accepts up to 50 video IDs per requestfor i in range(0, len(video_ids), 50):    batch = video_ids[i:i+50]    response = youtube.videos().list(        part="snippet,statistics,contentDetails",        id=",".join(batch)    ).execute()    for video in response.get("items", []):        snippet = video["snippet"]        statistics = video.get("statistics", {})        content = video.get("contentDetails", {})        views = int(statistics.get("viewCount", 0))        likes = int(statistics.get("likeCount", 0))        comments = int(statistics.get("commentCount", 0))        video_data.append({            "Video ID": video["id"],            "Title": snippet["title"],            "Published Date": snippet["publishedAt"],            "Views": views,            "Likes": likes,            "Comments": comments,
```

## **8. Important limitations**

1. The program analyses up to 200 videos by default. Change `MAX_VIDEOS = 200` to increase the limit.
2. YouTube may hide subscriber counts.
3. If likes or comments are disabled or unavailable, their values may be missing and the code treats them as zero.
4. This program analyses publicly accessible information, not private YouTube Analytics data.
5. API requests have quota limits. The standard allocation is generally 10,000 units per day for most API methods, subject to Google's current quota rules.&#x20;
